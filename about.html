About BioTrack

A simple research sample management application

What is BioTrack?

BioTrack is a web-based research sample and analysis tracking application designed to help researchers organize biological samples and monitor their analysis progress.

The application allows users to record sample information, track analysis status, search samples, monitor researcher workloads, and view basic project analytics.

Current Features

🧬 Sample Management

Add, edit and delete biological research samples.

🔎 Search & Filter

Quickly search samples and filter them by status.

📊 Analytics

Monitor total, pending, in-progress and completed analyses.

👩‍🔬 Researchers

View researcher workloads and sample assignments.

Technology

The current BioTrack prototype is built using HTML, CSS and JavaScript with browser localStorage for temporary data persistence.

The next development stage will introduce React, Node.js, REST APIs and PostgreSQL.
